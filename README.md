# Markdown 流程图渲染器

粘贴 Markdown，直接把里面的流程图、结构图渲染成图片，并一键复制到剪贴板。

纯静态单页（`index.html`），无需构建、无需后端，内容只在你的浏览器里处理。

**在线使用**：<https://attention-ai-yee.github.io/md-flowchart/>

## 功能

### 渲染
- 识别 ```` ```mermaid ```` 代码块，也可以直接粘贴一段 Mermaid 代码（流程图、时序图、类图、状态图、甘特图、饼图、思维导图、时间线等 Mermaid 支持的图都可以）
- 识别 ASCII 结构图 / 目录树（```` ```text ```` 或无语言的代码块中含 `┌─│└▶` 等框线字符）
- 一份文档里有多张图时，每张图一张卡片，标题取它前面最近的 Markdown 标题
- 左侧输入后右侧实时渲染；Mermaid 语法有误时，在对应卡片里显示错误信息

### 复制与导出
- **复制图片**：把这张图以 PNG 写入剪贴板，直接粘贴到文档、聊天、PPT
- **下载 PNG / 下载 SVG**：SVG 是矢量图，放大不糊
- **复制全部为一张图**：把所有图纵向拼成一张再复制
- **背景**：白色 / 透明 / 深色（深色时 Mermaid 自动换成深色主题）
- **清晰度**：2x / 3x / 4x，决定导出 PNG 的像素大小（页面显示不变）。倍数越高，放大后越清楚，文件也越大；超大的图会自动压低倍率，避免浏览器出错

### 交互
- **点击跳转**：点击图中的节点 / 连线 / 文字，左侧自动滚动并选中对应的代码。流程图最精确；ASCII 图按点击位置定位；其它图按图中文字去代码里匹配，找不到时跳到该图代码开头
- **放大预览**：点卡片里的「放大」或双击图，滚轮缩放、拖动平移、双击适应，Esc 关闭
- **卡片内编辑**：点「编辑」直接修改这张图的代码，右侧实时重绘，改动同步回左侧原文
- **ASCII 转 Mermaid**：ASCII 图的卡片上点「转为 Mermaid」，把原文里的这块替换成 Mermaid 代码，之后可以换主题、缩放、继续编辑。只识别 `┌─┐│└─┘`（含 `╭╮╰╯`）画的方框，且框之间要有连线或箭头；`+---+` 画的框、`├──` 目录树无法转换

### 输入与分享
- 直接粘贴，或「打开 .md」，或把文件拖进页面
- **分享链接**：把内容压缩进网址（`#d=...`），不经过任何服务器，别人打开就能看到同样的图。内容很长时链接也会很长，部分聊天软件可能截断
- 输入内容和设置自动保存在浏览器本地（localStorage）

### 外观
- 界面配色：自动（跟随系统）/ 浅色 / 深色
- 图主题：默认 / 中性 / 森林 / 深色

## 本地运行

```bash
git clone https://github.com/attention-ai-yee/md-flowchart
cd md-flowchart
python3 -m http.server      # 然后访问 http://localhost:8000
```

Mermaid 已内置在 `vendor/mermaid.min.js`（v11.4.1），**完全离线可用**。也可以直接双击 `index.html` 打开，但浏览器在 `file://` 下不允许写剪贴板，此时「复制图片」不可用，仍可下载。「复制图片」需要 HTTPS 或 localhost。

## 部署到 GitHub Pages

仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后一两分钟即可访问。仓库根目录的 `.nojekyll` 让 Pages 原样托管文件。

## 已知限制

- 为了让导出的图在各浏览器里都稳定，节点文字不渲染 HTML：`<b>粗体</b>` 会按字面显示，`<br/>` 换行仍然有效
- ER 图里的中文实体名和关系标签要加引号，如 `"用户" ||--o{ "订单" : "下单"`（Mermaid 自身的限制）
- 点击跳转：同一个词在代码里出现多次时，选中第一次出现的位置；同一对节点有多条连线时，选中第一条
- 「复制图片」依赖浏览器的剪贴板图片写入能力，主流现代浏览器支持；在 Safari / Firefox 上的表现尚未充分测试
- ASCII 图的 Tab 字符按 4 个空格处理；全角字符按 2 个半角宽度对齐，字体不同时可能有轻微错位

## 技术说明

- 单文件 `index.html` + `vendor/mermaid.min.js`，没有构建步骤和其它依赖
- 导出 PNG：Mermaid 输出 SVG → 序列化 → 画到 canvas → `canvas.toBlob` → `navigator.clipboard.write`
- ASCII 图直接按字符网格画到 canvas / 生成 SVG，不经过 Mermaid
